# Contributing to Kural Daily

Thank you for helping. Bug reports, corrections to the text or translations, accessibility
improvements and code are all welcome.

## Reporting a problem

Open an issue with:

- what you expected and what happened, and the steps to get there
- a screenshot or screen recording if it's visual
- phone model, Android or iOS version, and the app version (bottom of the You tab)

For a mistake in a Kural, its explanation or translation, give the Kural number and the correct
text with its source.

## Working on the code

```bash
git clone https://github.com/NiranjanRaj345/kural-daily.git
cd kural-daily
npm install
npm start            # then press a (Android), i (iOS) or w (web)
```

Before opening a pull request:

1. `npm run check` passes (typecheck, lint, tests).
2. New logic comes with tests in `__tests__/` where it can be tested without a device.
3. Visual changes: include before/after screenshots in Paper and Night, and check a Tamil-only and
   an English-only reading language.
4. Keep the app offline and private: no analytics, tracking, accounts or network calls. See
   [PRIVACY.md](PRIVACY.md); a change to what the app collects needs a change there too.
5. Keep pull requests focused on one thing; describe what changed and why.

Conventions:

- TypeScript, functional components, hooks; state in `store/useSettingsStore.ts` (zustand).
  Changing the persisted shape needs a `version` bump and a step in `migrateSettings`.
- Colours, spacing and type come from `theme/` (`useAppTheme`, `useType`, `space`, `radius`);
  don't hard-code colours, so every page style and accent keeps working.
- Bundled fonts are one file per weight: use `fontFamily` only, never with a bold `fontWeight`.
- UI text is plain and direct, in English with Tamil where it helps.

## The data

`assets/data/thirukkural.json` holds all 1330 Kurals. It's generated by
`scripts/transform_data.js`. Corrections are welcome in pull requests that edit the JSON directly;
say what changed and cite the source.
